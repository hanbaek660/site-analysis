# SiteDiagram — 대지분석도(주변현황도) 자동 생성 도구

주소 하나로 **항공사진 베이스 + 반경 원 + 도로망(도로명) + 주변 기업·시설명 + 산업단지 경계 + 위치도 인셋**이 들어간
대지분석 다이어그램 초안을 만들고, 라벨을 드래그로 다듬은 뒤 **PNG / PPTX(편집 가능) / SVG / DXF**로 내보내는 정적 웹앱입니다.
서버 프로그램·빌드 도구·외부 라이브러리가 전혀 없어서 **정적 파일을 내줄 수 있는 웹서버(사내 NAS 포탈, GitHub Pages 등) 어디에든 폴더째 복사하면 동작**합니다.

> **인수인계 메모 (2026-11)**
> - 이 폴더를 **업무프로세스 포탈(NAS 웹서버)** 하위에 두고 포탈 메뉴에서 새 탭으로 여는 방식으로 이관합니다. 절차는 §2, 자세한 내용은 함께 전달한 `인수인계서`를 보세요.
> - 이전 배포(참고용, 곧 중단): `https://juaworld.github.io/juadesign/sitediagram/sitemap-gen/`
> - `js/config.js`에 들어 있는 키 2개는 **이전 담당자 개인 계정**에서 발급한 것이고 `https://juaworld.github.io` 주소에 묶여 있어 **포탈 주소에서는 동작하지 않습니다.** 포탈 담당자 계정으로 새 키를 발급해(§1) `js/config.js`의 두 줄을 교체하세요.
> - 접근 제한 기능은 없습니다. 포탈이 사내망 전용이면 그 범위 안에서만 열립니다.

## 1. 준비물 — API 키 2개 (무료, 약 10분)

API 키는 **등록된 주소(도메인)에서만 동작**합니다. 먼저 사이트가 열릴 주소를 정하세요.
포탈에 두면 등록할 주소는 포탈의 접속 주소(예: `https://포탈도메인` 또는 `http://사내IP`)이고, 경로(`/tools/sitediagram/`)는 빼고 **프로토콜 + 호스트(+포트)** 까지만 등록합니다.

### 1-1. 카카오 JavaScript 키 — 주소 검색·주변 기업명 (developers.kakao.com)
1. 로그인 → 내 애플리케이션 → **애플리케이션 추가**
2. 앱 설정 → 플랫폼 → **Web 플랫폼 등록** → 사이트 도메인에 포탈 주소 추가
   (로컬 테스트도 하려면 `http://localhost:8765` 추가. 도메인은 여러 개 등록 가능)
3. 제품 설정 → **카카오맵 → 활성화 설정 ON** (안 켜면 403)
4. 앱 키 → **JavaScript 키** 복사 (REST API 키 아님)

### 1-2. 브이월드 인증키 — 항공사진 타일·연속지적도(필지)·건물 (www.vworld.kr)
1. 회원가입/로그인 → 오픈API → **인증키 발급** 신청
2. 서비스 URL: 포탈 주소, 활용 용도: 대지분석 자료 작성 등 → 발급(보통 즉시)
3. 키 복사. 키는 URL 1개에 묶이므로 로컬 테스트용은 `http://localhost:8765`로 하나 더 발급
4. 발급된 키는 **개발키(유효기간 1년)** 입니다. 만료 전 마이페이지에서 연장하거나 새로 발급해 교체하세요(§5 맨 아래).

> 키 없이도 동작은 합니다 — 배경은 Esri 위성영상, 데이터는 OSM만 사용. 다만 **주변 기업명(카카오)과 필지 경계(브이월드)는 키가 있어야** 나옵니다.
> 브이월드가 사내 IP 주소를 서비스 URL로 받아주지 않는 경우: 배경은 **Esri 위성영상**(⑤ 스타일 → 배경 지도)으로 쓰고, 필지는 **직접 그리기**로 입력하면 나머지 기능은 모두 동일하게 동작합니다.

## 2. 배치 (포탈 NAS 웹서버, 약 30분)

1. 이 폴더(`sitemap-gen`, 폴더 구조 그대로)를 포탈 웹루트 아래에 복사합니다. 예: `/tools/sitediagram/` → 접속 주소 `http(s)://포탈주소/tools/sitediagram/`
2. `js/config.js`를 열어 `vworldKey`, `kakaoJsKey`에 §1에서 발급한 키를 넣고 저장합니다. (`vworldDomain`은 비워두면 접속 주소를 자동 사용)
3. 포탈 메뉴에 **새 탭으로 여는 링크**를 겁니다. iframe 삽입은 권장하지 않습니다(지도 작업 화면이 좁아지고 드래그·단축키 동작이 어색해짐).
4. 접속해서 §6의 점검표대로 확인합니다.

주의
- `index.html`을 더블클릭해서 여는 `file://` 방식은 동작하지 않습니다(브라우저가 모듈 로딩을 막음). 반드시 웹서버를 통해 여세요.
- 포탈이 `http://`라도 됩니다. 외부 API 호출은 접속한 사람의 브라우저가 `https://`로 직접 하므로 NAS가 인터넷에 나갈 필요도 없습니다.
- 키는 주소 제한이 걸린 프론트엔드용 키라 소스에 들어 있어도 다른 사이트에서 도용할 수 없습니다.
- 이후 수정은 NAS의 이 폴더 파일을 직접 고치면 됩니다(캐시 때문에 사용자 쪽에서 Ctrl+F5 필요). 별도 빌드·배포 과정이 없습니다.

<details><summary>대안: GitHub Pages에 올리기 (회사 서버를 못 쓸 때)</summary>

1. github.com → New repository (Public) → "uploading an existing file"로 폴더 전체 업로드 → Commit
2. Settings → Pages → Source: Deploy from a branch → main / (root) → Save
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 접속. 키 등록 주소는 `https://<아이디>.github.io`
</details>

### 로컬에서 바로 띄우기
```bash
cd sitemap-gen
python3 -m http.server 8765      # 또는 npx serve .
# http://localhost:8765  (파일을 더블클릭해서 여는 file:// 는 API 키 도메인 제한 때문에 동작하지 않음)
```
개발·시연용 모의 환경: `python3 test/mock_server.py 8765` 후 `http://localhost:8765/?mock=1` (가짜 지도·가짜 데이터, 키 불필요)

## 3. 사용 순서

| 단계 | 할 일 | 비고 |
|---|---|---|
| ① 대지 설정 | 주소 검색 → 지도 이동. **[지도 클릭으로 대지 중심 지정]** → 대지 클릭. 대지명 입력 | 검색만 해도 대지 중심이 임시 지정됨 |
| | 필지: 그룹(기존공장/증축부지/대지) 선택 → **[지도 클릭으로 필지 추가]** → 필지 클릭 | 브이월드 연속지적도. 없는 경우 **[직접 그리기]** |
| ② 분석 범위 | 반경 원(기본 250 / 500 / 1,000m) 수정, 프레임 비율(16:9 등) 선택, **[반경이 다 보이게 맞추기]** | 화면에 보이는 프레임이 그대로 결과물 |
| | 위치도 인셋 모드·위치·크기·줌 | 인셋을 켜면 겹치는 라벨은 자동 이동. **인셋 지도는 휠로 확대/축소, 드래그로 이동** 가능(＋/－ 버튼, "대지 중심으로 되돌리기"). 인셋 제목은 비워두면 표시 안 함 |
| ③ 데이터 불러오기 | **[전체 자동 생성]** 클릭 (도로 → 구역 → 기업 순서, 보통 10~40초) | Overpass가 느리면 재시도. 소스 옵션에서 카카오 검색 키워드 조정 |
| ④ 레이어·라벨 | 지도에서 라벨 **드래그**(이동) · **더블클릭**(이름 수정) · **우클릭**(숨김). 목록 체크로 표시/숨김, 종류(색) 변경, 도로 색, **구역(산단·공원) 선 두께** | **겹치는 글자는 자동으로 숨겨지고 목록에 `겹침` 표시** → 드래그로 옮기면 다시 표시 |
| ⑤ 스타일 | 배경 지도, 흑백/밝기/대비, **흰색 안개 레이어 on/off + 불투명도**, 글자 크기, **글자 굵기(1~10, 기본 4)**, 도로 두께, 색상 | 글자 굵기 10 = 굵게, 6 이하 = 가는 글꼴(맑은 고딕 Semilight 등). 낮출수록 얇아지며 PNG·SVG·PPTX에 같은 두께로 반영. SITE 글자는 항상 굵게 |
| ⑥ 내보내기 | **PNG**(2000~5000px) · **PPTX**(PPT에서 편집) · **SVG** · **DXF**(EPSG:5186 / 로컬) · 프로젝트 JSON 저장 | PPTX: 사진은 그림, 선·면은 도형, 글자는 텍스트상자 |

작업 내용은 브라우저에 자동 저장되고, 상단 **[프로젝트 저장]** 으로 JSON 파일로도 보관·공유할 수 있습니다.

**되돌리기**: 상단 [↶ 되돌리기]/[↷] 또는 **Ctrl+Z / Ctrl+Y**(최근 60단계, 0.7초 안의 연속 변경은 한 단계로 묶임).
**설정 프리셋**(사이드바 맨 위): 스타일·반경·인셋·프레임 비율·데이터 옵션을 이름 붙여 저장하고 선택해서 적용. [내보내기]/[가져오기]로 JSON 파일로 다른 PC·팀원과 공유. 프리셋은 브라우저(localStorage)에 저장되므로 브라우저 데이터를 지우면 사라집니다 → 중요한 프리셋은 내보내기로 파일 보관.

## 4. 데이터 소스와 솔직한 한계

| 요소 | 소스 | 자동화 수준 | 한계 |
|---|---|---|---|
| 항공사진 배경 | 브이월드 Satellite 타일 (대안: Esri) | 자동 | 브이월드 타일이 CORS를 막으면 PNG 저장 시 Esri로 자동 대체를 제안 (미리보기는 브이월드 그대로) |
| 필지 경계 | 브이월드 연속지적도 `LP_PA_CBND_BUBUN` | 클릭 1회/필지 | 기존공장·증축부지 구분은 사람이 지정 |
| 도로망·도로명 | OSM Overpass | 자동 | 산단 내 소로의 도로명 누락 가능(OSM 입력 상태 의존). 라벨 위치는 자동 + 드래그 |
| 철도·하천 | OSM | 자동 | |
| 산업단지 경계 | OSM `landuse=industrial`(이름 있는 것) 또는 브이월드 산업단지 레이어 | 반자동 | 브이월드 레이어 ID는 환경별로 확인 필요(§5). 없으면 **직접 그리기** |
| 공원 | OSM `leisure=park` | 자동 | |
| 주변 기업·시설명 | 카카오 장소검색(키워드별 최대 45건) + OSM 건물명 (+브이월드 건물명 옵션) | 자동 60~85% 예상 | 소규모 공장은 누락될 수 있음 → 목록에서 체크/직접 추가. 이름이 길면 2줄로 자동 줄바꿈. 라벨만 표시(건물 위치점 없음) |
| 라벨 배치 | 충돌 회피 알고리즘 | 자동 | 자리가 없으면 겹치지 않도록 **숨김**(목록에 `겹침` 표시). 최종 미세조정은 드래그 또는 PPT에서 |
| 위치도 인셋 | 동일 타일 + 필지 + 범례 | 자동 | |

**현실적인 목표: 자동 생성 80% 초안 → 라벨 드래그/PPT 보정 5~10분.** 포토샵으로 2~4시간 걸리던 작업의 초안을 1분 안에 뽑는 것이 이 도구의 역할이고, 사람이 다듬은 보드와 100% 같아지지는 않습니다.

## 5. 자주 막히는 곳

| 증상 | 원인 → 조치 |
|---|---|
| 배경 타일이 안 뜸 | 브이월드 키 미입력/도메인 불일치 → 설정에서 키 확인, 브이월드 서비스 URL이 현재 주소와 같은지 확인 |
| 카카오 검색 403 | 카카오 콘솔 **제품 설정 → 카카오맵 활성화**, Web 플랫폼 도메인 등록 확인, JavaScript 키인지 확인 |
| "브이월드 요청 실패" | 도메인 등록 불일치(`http`/`https`, 끝 슬래시) → 설정의 "브이월드 등록 도메인"에 등록값 그대로 입력 |
| PNG 저장 시 "CORS" 안내 | 타일 서버가 캔버스 저장을 막음 → 안내대로 Esri 배경으로 저장하거나, 화면 캡처(브라우저 전체화면 F11 + 캡처) |
| Overpass 실패/느림 | 공용 서버 부하 → 잠시 후 재시도(3개 서버 자동 폴백). 프레임을 너무 넓게 잡지 않기(대지 중심 5km로 자동 제한) |
| 산업단지 경계가 안 나옴 | OSM에 이름 있는 industrial 폴리곤이 없음 → 브이월드 **오픈API → 2D 데이터 API → 데이터 목록**에서 "산업단지/산업입지" 레이어 ID 확인 후 설정에 입력, 또는 ①에서 **직접 그리기**(그룹: 아무거나 → 목록에서 종류를 '산업단지 경계'로 바꾸면 됨 — 현재는 구역 탭에서 종류 변경) |
| 글자가 깨짐(DXF) | DXF는 한글을 AutoCAD 표준 `\U+XXXX`로 기록 → AutoCAD/ZWCAD/BricsCAD 정상. 일부 무료 뷰어는 미지원 |
| PPT에서 글꼴 다름 | '맑은 고딕' 기준. 다른 글꼴로 바꾸려면 PPT에서 전체 선택 후 글꼴 변경 |
| 어느 날 갑자기 항공사진·필지가 안 뜸 | **브이월드 키 만료** 가능성(개발키 유효기간 1년 — 발급일을 `js/config.js` 주석에 적어두세요) → vworld.kr 로그인 → 마이페이지 → 오픈API 인증키 → 해당 키 **연장**(같은 키 유지, 6개월). 연장 횟수(3회)를 다 쓰면 새 키 발급 후 `js/config.js`의 `vworldKey` 교체 |
| 카카오 검색이 "쿼터 초과" | 카카오맵 API 무료 일일 한도 초과(하루 수십만 건 — 일반 사용으로는 거의 안 걸림). 다음 날 자동 복구 |
| 글자가 너무 굵거나 얇음 | ⑤ 스타일 → **글자 굵기** 슬라이더(기본 4). 10이면 굵게 |
